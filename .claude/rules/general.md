# Rule Set: General

Apply to all work unless a more specific rule file overrides.

## Rules
- State assumptions before acting.
- Respect existing project structure and conventions.
- Avoid unnecessary large refactors.
- Prefer small, reviewable changes.
- Summarize changed files and reasons.
- Do not invent requirements silently; flag missing details.
- Separate facts from assumptions in status updates.
- If risk is non-trivial, call it out early.

## Minimal response checklist
- [ ] Assumptions stated
- [ ] Scope boundaries stated
- [ ] Risks called out
- [ ] Deliverables clear
