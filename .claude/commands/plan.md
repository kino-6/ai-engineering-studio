# Command: /plan

## Goal
Produce a small implementation or documentation plan before changes.

## Rules
- Keep plan concise and actionable.
- Prefer smallest change that satisfies the goal.
- Call out assumptions and unresolved questions.

## Required output format
- **Goal**
- **Current understanding**
- **Files likely affected**
- **Proposed changes**
- **Risks**
- **Test plan**
- **Open questions / assumptions**

## Exit criteria
A reviewer can read the plan and understand what will change, why, and how success is verified.
