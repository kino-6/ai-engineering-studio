# Command: /start

## Goal
Classify incoming work and define a safe starting direction.

## Steps
1. Classify work type: investigation, requirements, design, implementation, bugfix, review, testing, or release preparation.
2. State assumptions and unknowns explicitly.
3. Identify risks (technical, schedule, quality, safety/compliance).
4. Define expected deliverables for this request.
5. Recommend agent perspective: architect, implementer, reviewer.

## Required output format
- **Work type:**
- **Request summary:**
- **Assumptions:**
- **Unknowns / questions:**
- **Key risks:**
- **Expected deliverables:**
- **Recommended agent:**
- **Why this agent:**
